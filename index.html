What is OpenBubble?

OpenBubble is an open source agent that helps you write code in your terminal, IDE, or desktop.

  • [*]LSP enabled — automatically loads the right LSPs for the LLM.
  • [*]Multi-session — start multiple agents in parallel on the same project.
  • [*]Share links — share a link to any session for reference or to debug.
  • [*]GitHub Copilot — log in with GitHub to use your Copilot account.
  • [*]ChatGPT Plus/Pro — log in with OpenAI to use your ChatGPT Plus or Pro account.
  • [*]Any model — 75+ LLM providers through Models.dev, including local models.
  • [*]Any editor — available as a terminal interface, desktop app, and IDE extension.

FAQ

What is OpenBubble?
OpenBubble is an open-source AI coding environment designed to make AI-assisted software development more structured and transparent. Instead of relying on a single undifferentiated AI response, OpenBubble can organize a task into different roles, such as planning, research, development, and review, allowing each stage to contribute to the final result.

In simple terms, OpenBubble gives one AI model a structured development workflow, so you can see how a coding task moves from understanding and planning to implementation and review.

That wording fits the project's actual direction without making the claim that OpenBubble is literally running multiple independent AI models. The architectural review also emphasizes that the role system is primarily about structural transparency and workflow organization.
How do I use OpenBubble?
Install via the command at the top of this page, then run openbubble in any project directory. The docs cover the rest.
Can I use my existing AI subscriptions with OpenBubble?
Yes. OpenBubble supports GitHub Copilot, ChatGPT Plus/Pro, and 75+ providers through Models.dev.
Can I only use OpenBubble in the terminal?
Yes — you can use OpenBubble straight from your terminal today. Just install it with the command at the top of the page and run openbubble in any project directory.

A dedicated desktop app is also in active development and will be released soon. It will bundle the same terminal-native experience with a more visual, point-and-click workflow — tabs, file previews, and a side-by-side session view — so you can pick whichever surface fits the task.
How much does OpenBubble cost?
OpenBubble itself is free to use. You connect it to your own AI provider and API key, so you only pay the provider you choose for the AI usage.

Your total cost therefore depends on the provider, model, and amount of usage. You can use a provider that offers free usage, a paid API, or your own local model, depending on what you prefer.
What about data and privacy?
OpenBubble does not store your code or context. Your data stays between you and your chosen model provider.
Is OpenBubble open source?
Yes. OpenBubble is MIT licensed and developed in the open on GitHub.
